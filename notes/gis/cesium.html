自定义切片方案类 ​

针对cesium加载自定义切片方案类，一个坐标系的自定义切片方案。

CustomGeographicTilingScheme.js 与 scheme.js。

  1. CustomGeographicTilingScheme.js
  • 继承自 Cesium.GeographicTilingScheme，是对 Cesium 原生地理切片方案的扩展。
  • 支持自定义原点、层级偏移、瓦片分辨率数组等高级功能，适用于需要灵活控制切片分布和分辨率的场景。
  • 主要用于自定义地图服务的切片坐标与地理坐标的转换。
  1. GeographicTilingScheme2.js
  • 自定义实现的地理切片方案，未继承 Cesium 的类，而是完全自定义实现。
  • 提供了基本的切片分块、坐标转换等功能，适合标准的地理切片需求。
  • 主要用于简单的地理切片坐标与地理坐标的转换。

二、主要属性与构造参数

属性/参数CustomGeographicTilingScheme.jsGeographicTilingScheme2.js
ellipsoid继承自父类，支持自定义支持自定义
rectangle继承自父类，支持自定义支持自定义
projection继承自父类支持自定义
origin支持自定义原点（如[-180, 90]）不支持
zoomOffset支持层级偏移不支持

三、主要方法对比

方法名CustomGeographicTilingScheme.jsGeographicTilingScheme2.js
tileXYToRectangle支持自定义原点、分辨率、偏移，适合多种坐标系标准实现，按等分方式分块
positionToTileXY支持自定义原点、分辨率、偏移标准实现，按等分方式分块
getNumberOfXTilesAtLevel / getNumberOfYTilesAtLevel继承自父类自定义实现，按2的幂次递增
rectangleToNativeRectangle / tileXYToNativeRectangle无有，支持弧度与度的转换

四、实现细节差异

  1. 分辨率与原点
  • CustomGeographicTilingScheme 支持通过 resolutions 数组和 origin 精确控制每一级的分辨率和切片起点，适合非标准切片体系（如部分国产地图服务）。
  • GeographicTilingScheme2 采用标准的等分切片方式，原点和分辨率不可灵活配置。
  1. 层级偏移
  • CustomGeographicTilingScheme 支持 zoomOffset，可灵活适配不同服务的层级定义。
  • GeographicTilingScheme2 不支持层级偏移。

五、适用场景建议

  • CustomGeographicTilingScheme.js
    适用于需要高度自定义切片体系（如自定义原点、分辨率、层级偏移）的场景，推荐用于对接国产地图服务、特殊投影或自定义瓦片服务。

  • GeographicTilingScheme2.js (GeographicTilingScheme2)
    实现简单，适用于标准地理切片体系，需求简单、无需自定义分辨率和原点的场景。

js
// GeographicTilingScheme2.js：自定义地理切片方案，用于地图瓦片的分块与坐标转换
function GeographicTilingScheme2 (options) {
  debugger // 调试用断点
  // 初始化参数，若未传入则使用默认值
  options = Cesium.defaultValue(options, Cesium.defaultValue.EMPTY_OBJECT)
  // 椭球体，默认为WGS84
  this._ellipsoid = Cesium.defaultValue(options.ellipsoid, Cesium.Ellipsoid.WGS84)
  // 切片范围，默认为最大矩形范围
  this._rectangle = Cesium.defaultValue(options.rectangle, Cesium.Rectangle.MAX_VALUE)
  // 投影方式，使用地理投影
  this._projection = new Cesium.GeographicProjection(this._ellipsoid)
  // 零级切片的X方向数量，默认为2
  this._numberOfLevelZeroTilesX = Cesium.defaultValue(
    options.numberOfLevelZeroTilesX,
    2
  )
  // 零级切片的Y方向数量，默认为1
  this._numberOfLevelZeroTilesY = Cesium.defaultValue(
    options.numberOfLevelZeroTilesY,
    1
  )
}

// 定义只读属性，便于外部访问
Object.defineProperties(GeographicTilingScheme2.prototype, {
  ellipsoid: {
    get: function () {
      return this._ellipsoid
    }
  },

  rectangle: {
    get: function () {
      return this._rectangle
    }
  },

  projection: {
    get: function () {
      return this._projection
    }
  }
})

// 获取指定层级下X方向的切片数量
GeographicTilingScheme2.prototype.getNumberOfXTilesAtLevel = function (level) {
  return this._numberOfLevelZeroTilesX << level // 位运算，等价于*2^level
}

// 获取指定层级下Y方向的切片数量
GeographicTilingScheme2.prototype.getNumberOfYTilesAtLevel = function (level) {
  return this._numberOfLevelZeroTilesY << level // 位运算，等价于*2^level
}

// 将弧度制矩形转换为度制矩形
GeographicTilingScheme2.prototype.rectangleToNativeRectangle = function (
  rectangle,
  result
) {
  // 检查rectangle参数是否定义
  Cesium.Check.defined('rectangle', rectangle)

  // 弧度转度
  const west = Cesium.Math.toDegrees(rectangle.west)
  const south = Cesium.Math.toDegrees(rectangle.south)
  const east = Cesium.Math.toDegrees(rectangle.east)
  const north = Cesium.Math.toDegrees(rectangle.north)

  // 若未传入result，则新建一个Rectangle对象
  if (!Cesium.defined(result)) {
    return new Cesium.Rectangle(west, south, east, north)
  }

  // 赋值到result对象
  result.west = west
  result.south = south
  result.east = east
  result.north = north
  return result
}

// 根据切片坐标获取度制矩形范围
GeographicTilingScheme2.prototype.tileXYToNativeRectangle = function (
  x,
  y,
  level,
  result
) {
  // 先获取弧度制矩形，再转为度制
  const rectangleRadians = this.tileXYToRectangle(x, y, level, result)
  rectangleRadians.west = Cesium.Math.toDegrees(rectangleRadians.west)
  rectangleRadians.south = Cesium.Math.toDegrees(rectangleRadians.south)
  rectangleRadians.east = Cesium.Math.toDegrees(rectangleRadians.east)
  rectangleRadians.north = Cesium.Math.toDegrees(rectangleRadians.north)
  return rectangleRadians
}

// 根据切片坐标获取弧度制矩形范围
GeographicTilingScheme2.prototype.tileXYToRectangle = function (
  x,
  y,
  level,
  result
) {
  const rectangle = this._rectangle

  // 计算当前层级的切片数量
  const xTiles = this.getNumberOfXTilesAtLevel(level)
  const yTiles = this.getNumberOfYTilesAtLevel(level)

  // 计算每个切片的宽度和经度范围
  const xTileWidth = rectangle.width / xTiles
  const west = x * xTileWidth + rectangle.west
  const east = (x + 1) * xTileWidth + rectangle.west

  // 计算每个切片的高度和纬度范围
  const yTileHeight = rectangle.height / yTiles
  const north = rectangle.north - y * yTileHeight
  const south = rectangle.north - (y + 1) * yTileHeight

  // 若未传入result，则新建一个Rectangle对象
  if (!Cesium.defined(result)) {
    result = new Cesium.Rectangle(west, south, east, north)
  }

  // 赋值到result对象
  result.west = west
  result.south = south
  result.east = east
  result.north = north
  return result
}

// 根据经纬度坐标获取所在切片的XY索引
GeographicTilingScheme2.prototype.positionToTileXY = function (
  position,
  level,
  result
) {
  const rectangle = this._rectangle
  // 判断点是否在切片范围内
  if (!Cesium.Rectangle.contains(rectangle, position)) {
    // 若不在范围内，返回undefined
    return undefined
  }

  // 计算当前层级的切片数量
  const xTiles = this.getNumberOfXTilesAtLevel(level)
  const yTiles = this.getNumberOfYTilesAtLevel(level)

  // 计算每个切片的宽度和高度
  const xTileWidth = rectangle.width / xTiles
  const yTileHeight = rectangle.height / yTiles

  let longitude = position.longitude
  // 处理跨越180度经线的情况
  if (rectangle.east < rectangle.west) {
    longitude += Cesium.Math.TWO_PI
  }

  // 计算X方向的切片索引
  let xTileCoordinate = ((longitude - rectangle.west) / xTileWidth) | 0
  if (xTileCoordinate >= xTiles) {
    xTileCoordinate = xTiles - 1
  }

  // 计算Y方向的切片索引
  let yTileCoordinate =
    ((rectangle.north - position.latitude) / yTileHeight) | 0
  if (yTileCoordinate >= yTiles) {
    yTileCoordinate = yTiles - 1
  }

  // 若未传入result，则新建一个Cartesian2对象
  if (!Cesium.defined(result)) {
    return new Cesium.Cartesian2(xTileCoordinate, yTileCoordinate)
  }

  // 赋值到result对象
  result.x = xTileCoordinate
  result.y = yTileCoordinate
  return result
}

class CustomGeographicTilingScheme extends Cesium.GeographicTilingScheme {
  constructor (options = {}) {
    super(options)
    this._origin = options.origin || [-180, 90]
    this._zoomOffset = options.zoomOffset || 0
    this._tileSize = options.tileSize || 256
    this._resolutions = options.resolutions || []
  }

  /**
 * 获取当前缩放偏移量。
 *
 * @returns {number} 当前的缩放偏移量。
 */
  get zoomOffset () {
    return this._zoomOffset
  }

  /**
     * 将瓦片坐标(x, y)和层级(level)转换为矩形范围。
     * 此函数用于根据瓦片坐标和层级计算出对应瓦片在地理空间中的矩形范围。
     * @param {Number} x - 瓦片的x坐标。
     * @param {Number} y - 瓦片的y坐标。
     * @param {Number} level - 瓦片的层级。
     * @param {Object} [result] - 可选参数，用于接收计算结果的矩形对象。
     * @returns {Cesium.Rectangle} 表示瓦片范围的矩形对象。如果没有可用的分辨率数据，则返回最大矩形范围。
     */
  tileXYToRectangle (x, y, level, result) {
    // 检查是否存在对应层级的分辨率数据，如果没有则返回最大矩形范围
    if (!this._resolutions || !this._resolutions[level + this._zoomOffset]) {
      return Cesium.Rectangle.MAX_VALUE
    }

    // 计算当前层级的瓦片大小
    const tileRes = this._resolutions[level + this._zoomOffset] * this._tileSize
    // 计算瓦片的西方、南方、东方、北方界限（单位：弧度）
    const west = Cesium.Math.toRadians(this._origin[0] + x * tileRes)
    const south = Cesium.Math.toRadians(this._origin[1] - (y + 1) * tileRes)
    const east = Cesium.Math.toRadians(this._origin[0] + (x + 1) * tileRes)
    const north = Cesium.Math.toRadians(this._origin[1] - y * tileRes)

    // 如果没有提供结果对象，则创建并返回一个新的矩形对象
    if (!Cesium.defined(result)) {
      return new Cesium.Rectangle(west, south, east, north)
    }
    // 如果提供了结果对象，则将其属性设置为计算得到的界限值，并返回该对象
    result.west = west
    result.south = south
    result.east = east
    result.north = north
    return result
  }

  /**
 * 将位置信息转换为瓦片坐标系中的XY坐标。
 * 此函数用于根据给定的位置和地图级别，计算出该位置在瓦片坐标系中的X和Y坐标。
 * 瓦片坐标系是一种将地球表面划分成多个矩形瓦片的系统，每个瓦片用X和Y坐标唯一标识。
 *
 * @param {Cesium.Cartesian3} position 需要转换的位置，使用经度、纬度度量。
 * @param {Number} level 地图的缩放级别。
 * @param {Cesium.Cartesian2} [result] 可选参数，用于存储计算结果的瓦片坐标。如果未提供，则会创建一个新的Cartesian2对象。
 * @returns {Cesium.Cartesian2} 返回包含X和Y坐标的瓦片坐标对象。如果无法进行转换，则返回一个新的空Cartesian2对象。
 */
  positionToTileXY (position, level, result) {
  // 检查是否存在对应级别的分辨率设置，如果没有，则返回空的Cartesian2对象
    if (!this._resolutions || !this._resolutions[level + this._zoomOffset]) {
      return new Cesium.Cartesian2()
    }

    // 计算当前级别的瓦片分辨率
    const tileRes = this._resolutions[level + this._zoomOffset] * this._tileSize
    // 将位置的经度和纬度转换为度
    const longitude = Cesium.Math.toDegrees(position.longitude)
    const latitude = Cesium.Math.toDegrees(position.latitude)

    // 计算瓦片的X坐标
    const xTileCoordinate = Math.floor((longitude - this._origin[0]) / tileRes)
    // 计算瓦片的Y坐标
    const yTileCoordinate = Math.floor((this._origin[1] - latitude) / tileRes)

    // 如果没有提供result参数，创建并返回一个新的Cartesian2对象，包含计算出的瓦片坐标
    if (!Cesium.defined(result)) {
      return new Cesium.Cartesian2(
        Math.max(0, xTileCoordinate),
        Math.max(0, yTileCoordinate)
      )
    }

    // 如果提供了result参数，将其X和Y属性设置为计算出的瓦片坐标
    result.x = xTileCoordinate
    result.y = yTileCoordinate
    // 返回设置好的result参数
    return result
  }
}

Cesium 3D Tiles 压平工具类

概述 ​

FlattenTileset 是一个用于 Cesium 3D Tiles 压平操作的工具类，可以将指定区域内的 3D 模型压平到指定高度，常用于建筑拆除、地形平整等场景。

主要功能 ​

  • 多格式坐标支持：支持 Cartesian3、经纬度数组、WKT、GeoJSON 等多种坐标格式
  • 批量压平：可同时处理多个 tileset 和多个压平区域
  • 高度控制：支持统一基准高度和区域独立高度设置
  • 实时更新：动态添加/删除压平区域，实时更新渲染效果
  • 性能优化：使用自定义着色器实现高效的压平效果

使用方法 ​

基本用法 ​

技术原理 ​

该工具通过以下步骤实现压平效果：

  1. 坐标转换：将世界坐标转换为 tileset 本地坐标
  2. 区域检测：使用射线法判断顶点是否在压平区域内
  3. 高度调整：对区域内的顶点应用压平高度
  4. 着色器渲染：通过自定义着色器实现实时压平效果

注意事项 ​

  • 压平区域必须至少包含 3 个点形成有效多边形
  • 支持复杂的多边形形状，但建议使用凸多边形以获得最佳性能
  • 压平操作会修改顶点位置，建议在操作前备份原始数据
  • 大量压平区域可能影响渲染性能，建议合理控制区域数量

export default class FlattenTileset {
    /**
     * @param {Cesium.Cesium3DTileset|Cesium.Cesium3DTileset[]} tilesets 三维模型集
     * @param {Object} [opt] 配置项
     * @param {Number} [opt.oHeight=0] 统一基准高度
     */
    constructor(tilesets, opt) {
      this.opt = opt || {};
      this.oHeight = this.opt.oHeight || 0;
      this.tilesets = [];
      this.tilesetConfigs = new Map(); // 存储每个tileset的配置信息
      this.regionList = []; // 存储所有压平面信息
  
      this.addTileset(tilesets);
    }
  
    addTileset(tilesets) {
      const addSingle = (tileset) => {
        if (!tileset || this.tilesets.includes(tileset)) return;
  
        try {
          const center = tileset.boundingSphere.center.clone();
          let cart = Cesium.Cartographic.fromCartesian(center);
          let centerXYZ = [
            Cesium.Math.toDegrees(cart.longitude),
            Cesium.Math.toDegrees(cart.latitude),
            cart.height,
          ];
          const matrix = Cesium.Transforms.eastNorthUpToFixedFrame(center);
          const localMatrix = Cesium.Matrix4.inverse(
            matrix,
            new Cesium.Matrix4()
          );
  
          this.tilesets.push(tileset);
          this.tilesetConfigs.set(tileset, {
            matrix,
            localMatrix,
            flatHeight: this.opt.flatHeight || 0,
            regions: [],
            centerXYZ,
          });
  
          // 应用现有压平面
          this.regionList.forEach((attr) =>
            this._addRegionToTileset(tileset, attr)
          );
          this._updateTilesetShader(tileset);
        } catch (e) {
          console.warn("Invalid tileset:", e);
        }
      };
  
      if (Array.isArray(tilesets)) {
        tilesets.forEach((t) => addSingle(t));
      } else if (tilesets) {
        addSingle(tilesets);
      }
    }
  
    removeTileset(tileset) {
      const index = this.tilesets.indexOf(tileset);
      if (index === -1) return;
  
      this.tilesets.splice(index, 1);
      this.tilesetConfigs.delete(tileset);
      tileset.customShader = undefined;
    }
  
    /**
     * 设置统一基准高度
     * @param {Number} height 新的基准高度
     */
    setOHeight(height) {
      this.oHeight = height;
      this.tilesets.forEach((tileset) => {
        if (tileset.customShader) {
          let _h = tileset.config.centerXYZ[2]
            ? height - tileset.config.centerXYZ[2]
            : height;
          tileset.customShader.setUniform("u_oHeight", _h);
        }
      });
    }
  
    /**
     * 设置指定tileset的压平高度
     * @param {Cesium.Cesium3DTileset} tileset 目标模型
     * @param {Number} height 压平高度（相对基准高度）
     */
    setFlatHeight(tileset, height) {
      const config = this.tilesetConfigs.get(tileset);
      if (!config) return;
  
      config.flatHeight = height;
      if (tileset.customShader) {
        tileset.customShader.setUniform("u_flatHeight", height);
      }
    }
    /**
     * 添加压平面（支持多种格式）
     * @param {Object} attr 参数
     * @param {Cesium.Cartesian3[]|number[][]|string|Object} attr.positions 坐标数据
     * @param {Number} [attr.height=0] 压平高度偏移
     * @param {String} [attr.id] 唯一标识
     * @param {String} [attr.format] 显式指定格式（可选值：cartesian/wkt/geojson/lonlat）仅支持单面
     */
    addRegion(attr) {
      if (!attr || !attr.positions) return;
  
      // 自动检测格式（可显式指定）
      const detectedFormat = attr.format || this._detectPositionFormat(attr.positions);
  
      try {
        // 转换为标准Cartesian3数组
        const positions = this._parsePositions(attr.positions, detectedFormat);
  
        // 验证坐标有效性
        if (!positions || positions.length < 3) {
          throw new Error("至少需要3个点组成多边形");
        }
  
        // 存储转换后的标准坐标
        attr.positions = positions;
        attr.id = attr.id || Cesium.createGuid();
        attr.height = attr.height || 0;
        this.regionList.push(attr);
  
        // 更新所有关联的tileset
        this.tilesets.forEach((tileset) => {
          this._addRegionToTileset(tileset, attr);
          this._updateTilesetShader(tileset);
        });
      } catch (e) {
        console.error("压平面添加失败:", e.message);
      }
    }
  
    /**
     * 自动检测坐标格式
     * @private
     */
    _detectPositionFormat(input) {
      if (Array.isArray(input)) {
        // 检测是否为二维数组 [[lon,lat], ...]
        if ((input[0].length === 2 || input[0].length === 3) && typeof input[0][0] === "number") {
          return "lonlat";
        }
        // 检测是否为Cartesian3数组
        if (input[0] instanceof Cesium.Cartesian3) {
          return "cartesian";
        }
      }
      // WKT字符串检测
      if (typeof input === "string" && input.match(/POLYGON\s*\(/i)) {
        return "wkt";
      }
      // GeoJSON检测
      if (input.type === "Feature" || input.type === "Polygon") {
        return "geojson";
      }
      throw new Error("无法识别的坐标格式");
    }
  
    /**
     * 坐标格式转换器
     * @private
     */
    _parsePositions(input, format) {
      switch (format) {
        case "cartesian":
          return input; // 直接使用现有Cartesian3数组
  
        case "lonlat":
          return input.map((p) =>
            Cesium.Cartesian3.fromDegrees(p[0], p[1], p[2] || 0)
          );
  
        case "wkt":
          return this._parseWKTPolygon(input);
  
        case "geojson":
          return this._parseGeoJSON(input);
  
        default:
          throw new Error(`不支持的格式: ${format}`);
      }
    }
  
    /**
     * 解析WKT多边形
     * @private
     */
    _parseWKTPolygon(wkt) {
      // 示例输入：POLYGON ((30 10, 40 40, 20 40, 10 20, 30 10))
      const match = wkt.match(/\(\(([^)]+)\)\)/);
      if (!match) throw new Error("无效的WKT格式");
  
      return match[1].split(",").map((pair) => {
        const [lon, lat] = pair.trim().split(/\s+/);
        return Cesium.Cartesian3.fromDegrees(parseFloat(lon), parseFloat(lat));
      });
    }
  
    /**
     * 解析GeoJSON
     * @private
     */
    _parseGeoJSON(geojson) {
      let coordinates;
      // 支持Feature或直接几何对象
      if (geojson.type === "Feature") {
        coordinates = geojson.geometry.coordinates;
      } else if (geojson.type === "Polygon") {
        coordinates = geojson.coordinates;
      } else {
        throw new Error("仅支持Polygon类型GeoJSON");
      }
  
      // 提取首个环（忽略孔洞）
      const ring = coordinates[0];
      if (!ring) throw new Error("缺少坐标数据");
  
      return ring.map((p) =>
        Cesium.Cartesian3.fromDegrees(p[0], p[1], p[2] || 0)
      );
    }
  
    _addRegionToTileset(tileset, attr) {
      const config = this.tilesetConfigs.get(tileset);
      if (!config) return;
  
      const localCoords = this._convertToLocalCoords(tileset, attr.positions);
      config.regions.push({
        id: attr.id,
        coords: localCoords,
        height: attr.height, // 存储区域高度
      });
    }
  
    removeRegionById(id) {
      this.regionList = this.regionList.filter((r) => r.id !== id);
  
      this.tilesets.forEach((tileset) => {
        const config = this.tilesetConfigs.get(tileset);
        if (!config) return;
  
        config.regions = config.regions.filter((r) => r.id !== id);
        this._updateTilesetShader(tileset);
      });
    }
  
    _convertToLocalCoords(tileset, positions) {
      const config = this.tilesetConfigs.get(tileset);
      return positions.map((pos) => {
        const local = Cesium.Matrix4.multiplyByPoint(
          config.localMatrix,
          pos,
          new Cesium.Cartesian3()
        );
        return [local.x, local.y];
      });
    }
  
    _updateTilesetShader(tileset) {
      const config = this.tilesetConfigs.get(tileset);
      if (!config) return;
  
      // 改为传递完整的regions数据（含高度）
      const funcStr = this._generateInPolygonFunctions(
        config.regions.map((r) => r.coords)
      );
      const mainLogic = this._generateShaderLogic(config.regions); // 传递regions而不是polygons
  
      tileset.customShader = new Cesium.CustomShader({
        uniforms: {
          u_tileset_localToWorldMatrix: {
            type: Cesium.UniformType.MAT4,
            value: config.matrix,
          },
          u_tileset_worldToLocalMatrix: {
            type: Cesium.UniformType.MAT4,
            value: config.localMatrix,
          },
          u_flatHeight: {
            type: Cesium.UniformType.FLOAT,
            value: config.flatHeight,
          },
          u_oHeight: {
            type: Cesium.UniformType.FLOAT,
            value: config.centerXYZ[2]
              ? this.oHeight - config.centerXYZ[2]
              : this.oHeight,
          },
        },
        vertexShaderText: `
                  ${funcStr}
                  void vertexMain(VertexInput vsInput, inout czm_modelVertexOutput vsOutput) {
                      vec3 modelMC = vsInput.attributes.positionMC;
                      vec4 modelPos = vec4(modelMC, 1.0);
                      vec4 tilesetLocalPos = u_tileset_worldToLocalMatrix * czm_model * modelPos;
                      vec2 position2D = tilesetLocalPos.xy;
                      float baseHeight = u_oHeight + u_flatHeight;
  
                      ${mainLogic}
  
                      // 默认不修改顶点
                      vsOutput.positionMC = modelMC;
                  }`,
      });
    }
  
    _generateInPolygonFunctions(polygons) {
      const lengths = [...new Set(polygons.map((p) => p.length))];
      return lengths
        .map(
          (len) => `
              bool isInPolygon_${len}(vec2 pt, vec2[${len}] points) {
                  int crossings = 0;
                  for (int i = 0; i < ${len}; i++) {
                      vec2 a = points[i];
                      vec2 b = points[(i+1)%${len}];
                      if ((a.y > pt.y) != (b.y > pt.y)) {
                          float x = mix(a.x, b.x, (pt.y - a.y) / (b.y - a.y));
                          crossings += int(x > pt.x);
                      }
                  }
                  return (crossings % 2) == 1;
              }
          `
        )
        .join("\n");
    }
  
    _generateShaderLogic(regions) {
      // 参数改为regions（含高度信息）
      return regions
        .map((region, i) => {
          const coords = region.coords;
          const height = region.height;
          const len = coords.length;
  
          const points = coords
            .map(
              ([x, y], j) =>
                `points_${i}[${j}] = vec2(${x.toFixed(5)}, ${y.toFixed(5)});`
            )
            .join("\n");
  
          return `
                  {
                      vec2 points_${i}[${len}];
                      ${points}
                      if (isInPolygon_${len}(position2D, points_${i})) {
                          float finalHeight = u_oHeight + u_flatHeight + ${height.toFixed(
                            2
                          )};
                          vec4 newPos = vec4(tilesetLocalPos.xy, finalHeight, 1.0);
                          vec4 worldPos = u_tileset_localToWorldMatrix * newPos;
                          vsOutput.positionMC = (czm_inverseModel * worldPos).xyz;
                          return; // 重要：修改后立即返回
                      }
                  }
              `;
        })
        .join("\n");
    }
    clearAllRegions() {
      // 保存当前tileset引用防止遍历过程中发生变化
      const currentTilesets = [...this.tilesets];
  
      // 分步清理确保完全重置
      this.regionList.length = 0;
  
      currentTilesets.forEach((tileset) => {
        const config = this.tilesetConfigs.get(tileset);
        if (!config) return;
  
        // 重置区域配置
        config.regions = [];
  
        // 完全重置shader
        tileset.customShader = undefined;
  
        // 可选：延迟更新避免重复渲染
        requestAnimationFrame(() => {
          this._updateTilesetShader(tileset);
        });
      });
    }
    destroy() {
      this.tilesets.forEach((t) => (t.customShader = undefined));
      this.tilesets = [];
      this.tilesetConfigs.clear();
      this.regionList = [];
    }
  }

Cesium性能优化

概述 ​

Cesium是一个强大的3D地球可视化库，但在处理大量数据时可能会遇到性能问题。本文将介绍一些常用的性能优化技巧。

主要优化策略 ​

1. 几何体优化 ​
  • 使用LOD（细节层次）技术
  • 合并几何体减少绘制调用
  • 使用几何体实例化
2. 纹理优化 ​
  • 压缩纹理格式
  • 使用纹理图集
  • 实现纹理流式加载
3. 渲染优化 ​
  • 启用视锥体剔除
  • 使用遮挡剔除
  • 优化着色器代码

javascript
// 启用视锥体剔除

const tileset = new Cesium.Cesium3DTileset({
    url: 'tileset.json',
    maximumScreenSpaceError: 16,
    maximumMemoryUsage: 512
});

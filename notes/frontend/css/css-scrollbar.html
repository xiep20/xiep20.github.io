scrollbar 滚动条美化

用法说明 ​

::-webkit-scrollbar 及其相关伪元素是 Webkit/Blink 内核浏览器（如 Chrome、Edge、Safari）专用的滚动条样式自定义方法。通过这些伪元素，可以对滚动条的宽度、颜色、圆角等进行美化。

代码示例 ​

css
/* 整体滚动条 */
::-webkit-scrollbar {
  width: 5px;
  height: 8px;
  background: #b9b9b9;
  border-radius: 5px;
}

/* 滚动条上的按钮（上下箭头等） */
::-webkit-scrollbar-button {
  display: none;
}

/* 滚动条滑块 */
::-webkit-scrollbar-thumb {
  border-radius: 10px;
  background: #54b5ff;
}

/* 滚动条轨道 */
::-webkit-scrollbar-track {
  border-radius: 10px;
  background: rgba(54, 87, 123, 0.9);
}

说明 ​

  • ::-webkit-scrollbar：设置滚动条整体的宽度、高度、背景色和圆角。
  • ::-webkit-scrollbar-button：设置滚动条两端的按钮，这里隐藏了按钮。
  • ::-webkit-scrollbar-thumb：设置滚动条滑块的颜色和圆角，滑块是用户拖动的部分。
  • ::-webkit-scrollbar-track：设置滚动条轨道的颜色和圆角，轨道是滑块移动的区域。

注意事项 ​

  • 仅支持 Webkit/Blink 内核浏览器（如 Chrome、Edge、Safari），在 Firefox、IE 等浏览器无效。
  • 建议搭配 overflow: auto 或 overflow: scroll 的元素使用。
  • 过窄的滚动条可能影响可用性，需根据实际需求调整宽度。
  • 滚动条样式属于非标准特性，未来可能有兼容性变化。

CSS 基础知识

CSS 选择器 ​

基本选择器 ​
  • 元素选择器：div, p, span
  • 类选择器：.class-name
  • ID选择器：#id-name
  • 通配符选择器：*
组合选择器 ​
  • 后代选择器：div p
  • 子元素选择器：div > p
  • 相邻兄弟选择器：div + p
  • 通用兄弟选择器：div ~ p
伪类选择器 ​
  • :hover - 鼠标悬停
  • :focus - 获得焦点
  • :active - 激活状态
  • :first-child - 第一个子元素
  • :last-child - 最后一个子元素
伪元素选择器 ​
  • ::before - 元素前插入内容
  • ::after - 元素后插入内容
  • ::first-line - 第一行文本
  • ::first-letter - 第一个字母

CSS 盒模型 ​

标准盒模型 ​
css

  width: 200px;

  margin: 10px;

怪异盒模型 ​
css
.box {
  box-sizing: border-box;
  width: 200px; /* 包含padding和border */
}

backdrop-filter: blur(1px);模糊滤镜等 ​

详情

backdrop-filter: blur(1px);模糊滤镜等

用法说明 ​

backdrop-filter: blur(1px); 用于给元素的背景区域（即元素后面的内容）添加模糊等滤镜效果。常见用法如下：

css
your-class {
  backdrop-filter: blur(1px);
}
  • 通常配合带透明度的 background-color 使用（如 rgba(255,255,255,0.5)），可实现毛玻璃、磨砂玻璃等视觉效果。
  • 需要元素有一定的“背景穿透”能力，通常设置 background: transparent 或半透明色。

影响布局的情况说明 ​

  • 本身不直接影响布局：backdrop-filter 只影响视觉效果，不会改变元素的尺寸、位置、层级等布局属性。
  • 子元素无法突破父元素的边界：当父元素应用 backdrop-filter: blur() 时，它会强制创建一个新的 层叠上下文，导致内部的绝对定位（position: absolute）子元素无法突破父元素的边界
  • 影响视觉层级：由于作用于元素后面的内容，如果元素是半透明的，模糊效果会叠加在下层内容上，可能让下层内容变得不清晰。
  • 兼容性问题：不是所有浏览器都支持 backdrop-filter，部分旧版浏览器或低端设备可能无效。

示例 ​

css
.glass {
  background: rgba(255, 255, 255, 0.3);
  backdrop-filter: blur(5px);
  /* 其它样式 */
}

效果：该元素后面的内容会被模糊处理，呈现出磨砂玻璃的视觉效果。

scrollbar 滚动条美化 ​

详情

scrollbar 滚动条美化

用法说明 ​

::-webkit-scrollbar 及其相关伪元素是 Webkit/Blink 内核浏览器（如 Chrome、Edge、Safari）专用的滚动条样式自定义方法。通过这些伪元素，可以对滚动条的宽度、颜色、圆角等进行美化。

代码示例 ​

css
/* 整体滚动条 */
::-webkit-scrollbar {
  width: 5px;
  height: 8px;
  background: #b9b9b9;
  border-radius: 5px;
}

/* 滚动条上的按钮（上下箭头等） */
::-webkit-scrollbar-button {
  display: none;
}

/* 滚动条滑块 */
::-webkit-scrollbar-thumb {
  border-radius: 10px;
  background: #54b5ff;
}

/* 滚动条轨道 */
::-webkit-scrollbar-track {
  border-radius: 10px;
  background: rgba(54, 87, 123, 0.9);
}

说明 ​

  • ::-webkit-scrollbar：设置滚动条整体的宽度、高度、背景色和圆角。
  • ::-webkit-scrollbar-button：设置滚动条两端的按钮，这里隐藏了按钮。
  • ::-webkit-scrollbar-thumb：设置滚动条滑块的颜色和圆角，滑块是用户拖动的部分。
  • ::-webkit-scrollbar-track：设置滚动条轨道的颜色和圆角，轨道是滑块移动的区域。

注意事项 ​

  • 仅支持 Webkit/Blink 内核浏览器（如 Chrome、Edge、Safari），在 Firefox、IE 等浏览器无效。
  • 建议搭配 overflow: auto 或 overflow: scroll 的元素使用。
  • 过窄的滚动条可能影响可用性，需根据实际需求调整宽度。
  • 滚动条样式属于非标准特性，未来可能有兼容性变化。
